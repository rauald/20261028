# 결정 기록

## 작성 원칙
- 기획, 플랫폼, 기술, 구조에 영향을 주는 결정을 기록한다.
- 단순한 파일 수정 내역은 기록하지 않는다.
- 제안과 확정된 결정을 구분한다.
- 기존 결정을 변경하면 이전 기록을 남기고 새 결정과 연결한다.
- 현재 유효한 결과는 관련 프로젝트 문서에도 반영한다.
