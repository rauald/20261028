# 이미지 생성 규칙

## 생성 규칙
- 이미지 생성 시 이미지 크기는 2진법 크기로 한다.
(단, 스프라이트 시트로 합칠 이미지는 2진법으로 하지 않고, 아래 내용을 참고하여 생성한다.)
- 이미지 최대 크기는 배경은 2048x2048 이고, 그 외에는 1024x1024 로 한다.
- 스프라이트 시트를 사용 할 경우 최대한 정사각형을 유지한다.
- 스프라이트 시트는 왼쪽위 부터 채우기 시작한다.
- 스프라이트 시트의 캐릭터 한 프레임 이미지 크기는 크게 해달라고 하면 256x256 으로 하고, 해당 말이 없으면 128x128 로 한다.
- 캐릭터 이미지를 생성할 때 비율을 유지한 채로 상하 or 좌우 둘 중 한 곳의 여백이 없게 생성한다.
- UI에 사용 할 이미지는 단독으로 사용하지 않으며, 모두 스프라이트 시트로 관리한다.
- 아이콘 이미지는 120x120 으로 한다.
- 버튼 및 팝업창 배경 이미지 처럼 늘려서 사용하는 것은 직사각형으로 만들어도 된다.
- UI 이미지를 생성 할 때 상하 or 좌우 둘 중 한 곳이상 여백이 없게 생성한다.
