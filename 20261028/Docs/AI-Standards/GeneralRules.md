# 공용 원칙

## 작업 원칙
- Unity 버전과 설치된 패키지를 확인한다.
- 기존 프로젝트의 개발 방식을 우선 확인한다.
- 작업 시작 전 기본 폴더를 아래 이름을 참고하여 생성한다.
```
Assets ← 최상위 폴더
ㅣ- 01_Scenes
ㅣ- 02_Scripts
ㅣ- 03_Prefabs
ㅣ- 04_Arts
ㅣ  ㅣ- 00_Image
ㅣ  ㅣ- 01_Material
ㅣ  ㅣ- 02_Texture
ㅣ- 05_Models
ㅣ- 06_Sounds
ㅣ- 07_Animations
ㅣ- 08_Effects
ㅣ- 09_Shader
ㅣ- 99_Etc
```
- 구현 전에 관련 문서를 확인한다.
- 현재 작업 범위에 필요한 기능을 구현한다.
- 프로젝트 기획서에 기획이 겹치거나, 다른 방식으로 쓴 것이 있다면 확인작업을 한다.
- 게임 규칙 등 중요한 미정 사항은 질문한다.
- 실제로 검증하지 않은 내용을 검증했다고 보고하지 않는다.
- 기본 폴더 설정을 제외한 모든 구현을 하기 전에 어떻게 이해했는지, 어떤 방식으로 만들지, 코드를 어떻게 쓸 건지를 보고하고, 승인되면 작업을 시작한다.
- 작업이 끝나면 '완료 보고'에 따라 순서대로 보고한다.
- 필요한 에디터 또는 패키지가 있다면, 무엇이 필요한지 보고하고, 승인하면 진행한다.
- 파일을 이동시킬 때 연결된 .meta 파일을 함께 이동시킨다.

## 확인 작업
- 중복 된 기획인데, 다른 방식인 것
- 내용을 정확히 이해하지 못할 때
- 위 작업 원칙에 없는 내용 일 때

## 완료 보고
- 구현한 기능 (해당 스크립트 경로와 스크립트도 보고한다.)
- 추가된 파일
- 변경된 파일
- 삭제된 파일
- 검증 결과
- 검증하지 못한 항목
- 다운 받은 패키지 리스트

## 금지 사항
- 구현 전에 보고한 내용 외 추가 작업
- 게임 특성에 벗어나는 작업
